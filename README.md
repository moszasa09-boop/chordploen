# คอร์ดเพลิน

เว็บดูคอร์ดสำหรับเล่นบนเวที อยู่ครบในไฟล์เดียว ไม่ต้องติดตั้งอะไร

**เปิดใช้งาน:** https://moszasa09-boop.github.io/chordploen/

## ฟีเจอร์

- เปลี่ยนคีย์ +/− หรือเลือกคีย์ปลายทางได้ทันที คอร์ดทั้งเพลงเปลี่ยนตาม
- แนะนำคาโป้ที่จับคอร์ดง่ายที่สุดให้อัตโนมัติ
- แผนภาพคอร์ดสำหรับกีตาร์ อูคูเลเล่ และเปียโน แตะคอร์ดเพื่อฟังเสียง
- โหมดตัวเลข (Nashville) และโหมดคอร์ดง่าย
- เลื่อนอัตโนมัติ, เสียงคลิกตาม BPM, โหมดเวที (เต็มจอ ตัวใหญ่ จอไม่ดับ)
- เซ็ตลิสต์ 4/11 Krungsri Tech Day ครบ 8 เพลง พร้อมชาร์ตคอร์ด (คอร์ดอย่างเดียว) อ้างอิงจาก dochord.com
- หน้า "เตรียมเนื้อร้องทั้งเซ็ต" สำหรับวางเนื้อร้องที่คัดลอกจากหน้าเว็บคอร์ดครบทุกเพลงในหน้าเดียว

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวเว็บที่ GitHub Pages เปิดให้ และดับเบิลคลิกเปิดใช้แบบ offline ได้ |
| `src/page.html` | ซอร์สต้นฉบับ แก้ไขที่ไฟล์นี้ (ใช้เผยแพร่บน Claude ด้วย) |
| `scripts/build.sh` | สร้าง `index.html` จาก `src/page.html` |

ดาวน์โหลดทั้งหมดได้จากปุ่ม **Code → Download ZIP** บนหน้า GitHub

## แก้ไขแล้วอัปเดตเว็บ

```bash
./scripts/build.sh
git add -A && git commit -m "อัปเดตเพลง" && git push
```

GitHub Pages จะอัปเดตเว็บเองภายใน 1–2 นาที

## ข้อควรรู้

- **ไม่มีเนื้อร้องในไฟล์นี้** เพราะเนื้อเพลงมีลิขสิทธิ์ ผู้ใช้วางเองจากหน้าเว็บคอร์ด
- เนื้อร้องที่วางไว้จะเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ถ้าย้ายเครื่องหรือเปลี่ยนลิงก์ ให้ใช้ปุ่ม "คัดลอกข้อมูลสำรอง" แล้วไป "กู้คืน" ที่อีกฝั่ง
- ชาร์ตคอร์ดมาจากเว็บที่ผู้ใช้ส่งคอร์ดเข้ามาเอง ควรลองเทียบกับเพลงจริงก่อนเล่น
